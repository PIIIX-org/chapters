# scriptorium: Surface 01 of 04 — Knowledge Graph Folio (01-graph)

- **Composition Anchor**: `right-rail-caption` (fluid graph canvas / 340px illuminated catalog rail)
- **Background Mode**: `flat-surface` (warm mineral charcoal in dark mode, papyrus vellum in light mode)
- **Frame Spec**: 1440×900 desktop screen, 52px warm rail, fluid illuminated graph area.

## Layout Specification
- **Substrate**: Warm mineral charcoal `#101216` (dark) or crisp vellum `#F7F6F2` (light).
- **Graph Presentation**: Treated as an illuminated scholarly network diagram. Fine hairline connectors with subtle calligraphic taper.
- **Node Styling**:
  - Vault Notes: Small manuscript seal glyphs with subtle sepia ink outline (`#D4A359`).
  - Code Nodes: Structured geometric diamond points (`#7C8FD9`).
  - Edges: Delicate sepia stroke (0.8px) with ink-wash attenuation over distance.
- **Marginalia Catalog (Right, 340px)**:
  - Archival summary of active community clusters (styled like book chapters).
  - Selected Chapter: "Chapter IV: Computational Graph Engine" (contains 18 notes, 32 code nodes).
  - Folio notes with excerpted quotes and bidirectional wikilink citations.

## Typography Scale
- **Catalog Chapter Heading**: Geist Sans, 16px / 22px, Medium (`wght 500`), `#EDEBE8`.
- **Marginalia Notes**: Geist Sans, 13px / 20px, Normal (`wght 400`), `#A8A39D`.
- **Node Labels**: Geist Sans, 11px / 14px, Medium (`wght 500`), `#EDEBE8`.
- **Archival Notation**: Geist Mono, 10px / 14px, Semibold (`wght 600`), tracked +0.08em, `#D4A359`.

## Paired Color Tokens & Measured Contrast
- Substrate `#101216` vs Text `#EDEBE8`: **15.8:1** (Passes WCAG AAA)
- Substrate `#101216` vs Sepia Ink `#D4A359`: **8.2:1** (Passes WCAG AAA)
- Catalog Card `#171A20` vs Marginalia `#A8A39D`: **6.1:1** (Passes WCAG AA)

## Content Direction
Scholarly exploration of the Chapters knowledge graph, displaying how concepts interleave with code files as interconnected chapters of an intellectual codex.
