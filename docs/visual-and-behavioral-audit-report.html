CRITICAL
DEF-01
 Shell & Global Workspace <Rail> & <main> Layout Root

Floating Rail is fixed at left-2.5 with z-30 (width ~64px), while <main> has w-full starting at x=0. The rail physically occludes the left 90-180px of page content across /vaults, /repos, and /team. In Vaults, the search bar and the first card column are partially obscured. In the Editor workspace, the bottom rail card physically overlaps note titles in the FileTree sidebar (cutting "graph-explorer" in half).

Impact: Severe visual obstruction and click interception across all core dashboard pages.
 <main> container must provide clearance for the rail (e.g. pl-20 or CSS grid column template), or the rail must be part of document flow on desktop and a drawer/bottom-bar on mobile. client/src/components/shell/AppShell.tsx:71
CRITICAL
DEF-02
 Repositories & Code Viewer Top Action Bar

The green "• SYNCED" status pill is absolutely positioned directly over the "Connect a repository" button. The right half of the button is obscured and physically unclickable.

Impact: Visual corruption and inability to click repository connection CTA in file viewer.
 Badges and action buttons should reside inside a flex row with gap-2 or gap-3 and shrink-0 protection. client/src/routes/repos/$id/files/$.tsx:112
CRITICAL
DEF-03
 Responsive Design (375px) Global Shell & Top Bars

On 375x812 mobile viewports, the desktop floating rail is NOT hidden or collapsed; it consumes ~50px of horizontal real estate. Simultaneously, the top bar squeezes 6-7 full buttons into 320px: vault title truncates to "VA...", "+ New vault" truncates to "+ New va", and search overflows viewport edge.

Impact: Unusable mobile navigation and broken touch ergonomics.
 Floating rail should hide on mobile (replaced by a BottomNav bar or hamburger drawer); top bar controls should collapse into a "..." More dropdown. client/src/components/shell/AppShell.tsx & VaultHeader.tsx
CRITICAL
DEF-04
 Editor & Version History <RevisionDiffModal> / API Mock

Clicking "Preview" on any historical revision opens RevisionDiffModal but renders a red banner: "method not allowed" and displays "Note body is empty." The mock server (client/mock/server.mjs) registered DEL for revisions but omitted GET for revision snapshots.

Impact: Revision preview functionality fails completely with HTTP 405 error during frontend development/mock testing.
 The mock server should implement GET /vaults/:id/revisions/:revisionId returning the note snapshot so users and testers can preview diffs. client/mock/server.mjs:160 vs RevisionHistory.tsx:75
HIGH
DEF-05
 Repositories & Sharing Repository Settings Dialog

In Repository Settings > Access & Sharing, the list of shared members displays raw database UUIDs (e.g. "ebc363dc-54b8-4d77-8905-007e8e29b492") instead of human-readable user names, emails, or avatar chips.

Impact: Severe usability degradation; repository administrators cannot identify which people have access.
 Grantee UUIDs should be resolved to user profiles (name, email, avatar) using user lookup or hydrated share objects. client/src/components/repos/RepositorySettingsDialog.tsx:142
HIGH
DEF-06
 Settings & Security Two-Factor Authentication Setup

In Settings > Security > Two-Factor Authentication, the setup dialog only renders a raw text URI string ("otpauth://totp/...") and manual secret key. There is NO scannable visual QR code image provided.

Impact: High onboarding friction; forces mobile authenticator users to manually type 32-character base32 strings.
 A standard QR code (canvas or SVG) should be generated and displayed so users can scan it directly with authenticator apps (Google Authenticator, 1Password, etc.). client/src/routes/settings/index.tsx:280
HIGH

 Settings & MCP MCP Agent Tokens Table

 Responsive & Mobile Editor Editor Top Bar

 Shell Chrome Scope Picker & Notifications

Clicking the Notification Bell icon does not automatically close an already open Scope Picker dropdown. Both popovers remain active and visually collide in the top-left area.

MEDIUM
DEF-10
 Admin Center & Radix UI <TabsTrigger> Event Handling

Radix UI Tabs ignore synthetic .click() and .dispatchEvent(new MouseEvent("click")) JavaScript events. They require hardware-level pointer down/up events to switch tabs. This indicates strict pointer-event handlers that can interfere with certain assistive touch devices or test automations.

Impact: Potential friction with assistive touch controllers and synthetic UI event handlers.
 Tabs should respond smoothly to standard click, touch, and keyboard (Space/Enter/Arrow) navigation. client/src/routes/admin/index.tsx:64
MEDIUM
DEF-11
 Knowledge Graph Graph Controls Bar

Chapters includes rich backend and MCP graph pathfinding capabilities (find_graph_path), but the Graph Canvas UI provides no visible button, icon, or modal trigger to run node-to-node pathfinding.

Impact: High-value graph traversal feature is completely hidden from visual UI users.
 Add a "Find Path" button in GraphControls.tsx that opens a pathfinding modal allowing users to pick source & target nodes. client/src/components/graph/GraphControls.tsx:42
MEDIUM
DEF-12
 Editor Workspace Wikilink Autocomplete Popover

When typing "[[" near the bottom or right boundary of the editor viewport, the autocomplete popup renders off-screen without auto-flipping upward.

Impact: Users cannot see autocomplete options when typing wikilinks near bottom of screen.
 Popover position calculation should include viewport collision detection and flip above the cursor if space below is < 200px. client/src/components/notes/editor/WikilinkExtension.ts

 Vaults & Danger Zone Vault Deletion Button

In Vault Settings > Danger Zone, clicking "Delete Vault" executes immediately without requiring the user to type the vault name to confirm destruction.
