Root Cause & Production Impact
✓

Fix 1: Vendored OKF Schema Availability Container Tests

test/okf-conformance.test.ts resolves schemas via resolve(__dirname, '../../vendor/okf/schemas'). Without copying vendor/, containerized test suites fail on missing JSON schemas.

✓

Fix 2: PostgreSQL Client for Automated Backups Disaster Recovery

server/src/export/backup-service.ts shells out to pg_dump for native database exports. Without postgresql-client in node:24-slim, backup cron jobs fail with binary not found.

Hybrid Vector Search: Memory Tuning
Torture Test (10 Concurrency)

Bottleneck Isolated: At shared_buffers = 128MB, HNSW index vector operations spill to disk under concurrency, averaging 4.49s. Increasing to 512MB keeps vectors in RAM, cutting latency to ~1.2s.

AI Runaway Loop: CPU Spike Mitigation
PR #355 Telemetry

Opportunity: server/src/notes/store.ts:readNote() runs js-yaml on every request (53.4% CPU spike). Utilizing the pre-parsed DB row frontmatter or an in-memory cache cuts read overhead by ~60%.

Dual-Layer Ingress Protection Architecture (Validated in PR #355)

1. MCP Ingress Rate Limiter

server/src/mcp/rate-limit.ts enforces 120 calls / minute per connection token.

Request #121 → Immediate HTTP 429 Too Many Requests (Bypasses DB & Disk entirely).

2. Fastify REST Rate Limiter

@fastify/rate-limit protects HTTP endpoints at 1,000 calls / minute per IP.

Prevents crawler exhaustion; protects authentication brute-force and asset ingress.

3. PostgreSQL Connection Queue

Configurable connection pool (max: 25) with graceful backpressure queuing.

Tested under 35 concurrent requests: 0 socket drops, 0 crashes, DB CPU remained < 1.6%.
