## Minor
- `.github/scripts/lab-plan.mjs` (`reuseFrom`): check runs carry no event or branch, so a parent `bench-gate` or `lab` run that came from a `workflow_dispatch` on the same sha counts. For example, a maintainer's `-f bench=chapters` run that passed after the PR's all-suite run failed would satisfy a later record head. This needs write access, and the same tree is what was tested. Reuse also ignores a base that moved since the parent ran. The merge queue re-runs everything, so neither breaks the gate.
- The `lab` and `bench-gate` header comment in `elara-lab.yml` and `docs/agents/lab.md` could mention the reuse path.
