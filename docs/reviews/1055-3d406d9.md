## Minor
- **`limit` caps impact at 50 sites per level with no cursor.** The docs say "raise it for more", but 50 is already the maximum, and level 1 of `createActiveUser` has 433 sites. If `limit` is the only way to see more, the docs promise something it cannot give.
- **Frontier cut is not flagged.** `IMPACT_FRONTIER` (200) and the 500-row cut silently shorten levels 2 and 3. Their `total` is not marked `capped`, so a level can look complete when it is not.
- **`intRange` advertises `"type":"number"` with no bounds** for `limit`, `depth` and `community` in `tools/list`. The integer type and range are lost to schema-driven clients, and the error appears only at call time. The manual says the range is checked but not listed, so this is a documented trade, but the integer type is lost along with it.
- **Duplicate-looking rows.** `impact textArray depth 2` shows `extraction-queue.ts:686` twice with different `to`, where one source line makes two calls. This is accurate but easy to misread.
