## Minor
- `timeBound` refuses years 0000–0099 (`server/src/graph/assemble.ts:364`).
  - `Date.UTC` reads years 0–99 as 1900–1999, so the real-day check fails. `0001-01-01` and `0099-12-31` now match nothing, though the old `Date.parse` accepted them and the docs say any `YYYY-MM-DD` is accepted.
  - I confirmed this with a node probe. The probe also confirmed that `2023-02-29` is refused and `T24:00` rolls over to the next day.
  - Fix: `const midnight = new Date(0); midnight.setUTCFullYear(+year, +month - 1, +day)`.
