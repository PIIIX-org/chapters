## Findings (blocking)
1. **The lab gate is red: 3 regressions in the fast tier, and the PR does not update the lab fixtures that hard-code symbol counts.**
   - Run 40052282961, job `lab`, on the dev merge: "Lab gate: FAIL … 3 regressions". The same job passed on #980 (run 40050737890), so the delta here causes it.
   - `lab/tests/fix-crash-catchup.test.ts:85-86`: `final.symbols === FILES * 3` fails with "1200 symbols total (expected 900)". Its fixture `class Beta${i} { run() {…} }` now also yields `method Beta.run`, so each file has 4 symbols.
   - `lab/lib/bundle-test.ts:160`: `f.symbols === 2` fails 0/30 (critical) and 0/10 (high). `smallTs`'s `class …Cls { go() {} }` now yields 3 symbols per file.
   - `lab/lib/bundle-test.ts:226`, full tier (not run on this PR): `bundleRow.symbols === DECLS` for `zz-fix-pretty-bundle` will fail as well. I ran `extractStructure` on the exact `makeBundle(true)` output: it gives **1,080** symbols (810 function, 90 class, 180 method) against the expected 900.
   - Fix: update the three expectations so the lab counts methods. For example, `FILES * 4` with a reason, 3 symbols per small file, and `DECLS + 2 * Math.floor(DECLS / 10)` methods for the pretty bundle. Then attach a passing lab run (fast, plus full `zz-fix-pretty-bundle`).

2. **A file with more than 8,191 symbols now fails extraction completely (`MAX_PARAMETERS_EXCEEDED`), and it loses its file embedding too** (`server/src/repositories/extraction-queue.ts:382-392`).
   - The symbol insert is a single `values(...)` with 8 bound parameters per row: `fileId, name, kind, parent, startLine, endLine, snippet, embedding`. postgres.js caps a statement at 65,534 parameters.
   - Reproduced on the dev merge with a 9,000-line `export const K${i} = ${i}` file:
     - The job threw `MAX_PARAMETERS_EXCEEDED: Max number of parameters (65534) exceeded`.
     - The result was 0 symbols, `embedding` null and `extractor_version` 0.
     - The job is retried and re-queued at every boot.
   - With `server/src` reverted to 6ec2a87, the same file extracts: version 2, file embedded.
   - Before this PR the limit was about 9,362 rows (7 parameters each), and it counted only function, class, interface and type. The PR adds a parameter per row and makes every exported const and method a row. Generated constant, enum or key tables are therefore the files that newly lose even their file vector.
   - Fix: insert the symbol rows in chunks inside the same transaction, e.g. `for (let k = 0; k < rows.length; k += 1000) await tx.insert(repositoryFileSymbols).values(rows.slice(k, k + 1000))`. Add a test with more than 8,192 symbols.
