2. **`checks` fails: three client tests** (run 41180664256).
   - The failures:
     - `client/src/hooks/useCodeMirrorEditor.test.tsx:57`: `.cm-md-h1` is null.
     - `client/src/components/repositories/CodeViewer.test.tsx:188`: the keyword list is empty.

   - Cause: `@codemirror/language` 6.13.1 resolves `@lezer/common@1.5.4`, while `lang-markdown`, `@lezer/markdown` and `@lezer/highlight` stay on 1.5.3 (`pnpm-lock.yaml:1073,1076`). The base lockfile had a single copy. With two copies, highlighting no longer matches.

3. **hocuspocus 4.7.1 lets any editor remove an agent's presence** (`server/src/sync/collab-server.ts:550`; the bump is at `server/package.json:28`).

   - Any editor can then remove an MCP agent's presence, which breaks #481's rule that a client speaks only for itself.
   - No test covers `stripAgentClaims` or the awareness hook; `server/test/agent-presence-renew.test.ts` does not.
   - A human commit must destructure `removedClients` in the hook and extend `stripAgentClaims` to take it. It should call `removedClients.delete(id)` for every agent client id. It must add a regression test: a client sends a null-state removal for the agent's id, and the agent stays present.
   - I derived this from the 4.7.1 source diff. The #990 review ran a scratch test of the same scenario.
