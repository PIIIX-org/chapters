What the Industry Lacks (Market Blindspots)

4 Gaps
The Code-Doc Schism ("The Truth Gap")
Documentation tools live in a separate universe from Git repositories, causing ADRs and system specs to rot within weeks.
Documentation Drift Market Void
›
💡 In Plain English: Imagine an architectural blueprint that never updates when the builders knock down a wall. New engineers consult the blueprint, walk directly into a brick wall, and learn to never trust documentation again.

Why Existing Tools Fail

Confluence, Notion, and Slite are decoupled from Git. When an engineer refactors code in a PR, updating external wiki pages is treated as an optional "Friday afternoon chore" that gets abandoned under deadline pressure.

The Chapters Solution

Host Markdown notes and synced Git repositories in the same application. Notes link to live code symbols (ASTs) rather than fragile line numbers, and webhook sync triggers drift alerts automatically.

The "Team Obsidian" Paradox
Developers adore Obsidian's local-first speed and Markdown on disk, but deploying it across a team results in painful sync collisions and zero permissions.
Multiplayer PKM
›
💬 Hacker News Consensus: "We tried sharing an Obsidian vault with Git. Within two days, non-technical team members couldn't commit, and two devs editing the same note created merge conflicts that clobbered notes. We gave up and went back to Notion."

The Missing Middle

Obsidian is an uncompromising single-player PKM. Teams want its plain text files, instant keyboard navigation, and wikilink graph, but need conflict-free CRDT collaborative editing (Yjs) and server-side RBAC.

How Chapters Solves It

Notes live as plain Markdown files on disk, but live editing is coordinated through an in-memory Yjs collaborative CRDT relay with real-time permissions and revision snapshots.

The Global Graph "Hairball" Fallacy
Massive 3,000-node global graphs in PKM tools are dismissed as "aesthetic vanity" that provide zero daily navigation utility.
Graph UX
›
💡 In Plain English: Looking at a map of every single road in the entire world simultaneously is useless for driving home from the grocery store. You need a turn-by-turn local view of your immediate neighborhood.

The Problem in Obsidian & Roam

Users stare at an overwhelming bouncing ball of yarn. Finding a specific concept is 100x slower than pressing Cmd+K.

The High-Utility Graph Pattern

Engineers need Local Ego Graphs (showing only 1-2 degrees of separation from the current note/file), Concept Pathfinding (shortest path between two nodes), and Supernode Bottleneck Spotting.

The AI Agent "Token Burn" Trap
Current tools either dump massive raw files into AI agent contexts or use naive vector search that destroys architectural hierarchy.
MCP Architecture
›

The Pain for AI Coding Agents

When Claude Desktop, Cursor, or Devin queries a repository, reading 10 full files burns 50k tokens and causes "lost-in-the-middle" reasoning errors. Naive RAG chunks miss function call hierarchies.

The Progressive Disclosure Fix

The knowledge base must serve summary catalogs and AST function headers first (Layer 1). The agent uses specific MCP tools to traverse relationships (Layer 2) and only reads exact line blocks on demand (Layer 3).

What Users Crave (Unmet Desires & Emotional Drivers)

3 Core Desires
"Why Does This Code Exist?" — The Living Lineage
Developers desperately want to click a function in code and instantly see the ADR, whiteboard spec, or incident post-mortem that conceived it.
Developer Experience
›
💬 Reddit r/programming: "I spent 3 days debugging why an odd retry delay was set to 42 seconds, only to find an unlinked Slack discussion from 2 years ago explaining a third-party gateway bug. If our code linked to the design decision, I would have known in 5 seconds."
Sub-Millisecond Keystroke Latency
Engineers crave tools that feel as fast as Vim/Sublime, rejecting the input lag and heavy DOM repaints of Notion and Confluence.
Performance
›

A local CodeMirror 6 editor with zero server roundtrip on typing, paired with asynchronous WebSocket sync, delivers the visceral satisfaction that keeps developers inside the wiki rather than writing notes in private text files.

Zero-Maintenance Living Documentation
Documentation that validates itself in CI, flags its own staleness, and updates AST references automatically when code moves.
Automation
›

When documentation maintenance feels like filing paperwork, it dies. When documentation automatically flags: "Commit abc1234 changed the Session schema; 2 notes need review", keeping documentation fresh becomes an effortless automated guardrail.

What We MUST Add (Table Stakes / P0)

6 Priorities
1. Local Ego Graph (1–2 Hops) in Inspector
Add an interactive neighborhood graph panel directly in the note and repository inspector, showing immediate 1-2 hop relationships.
P0 Table Stakes client/src/components/vault/NoteInspector.tsx
›

Why It Is P0

Global graphs are overwhelming; local graphs are indispensable. Placing an ego graph right beside the active note transforms the graph from an occasional dashboard into a continuous thinking partner.

Implementation Plan

Query existing /api/vaults/:id/graph filtered to depth=1..2 around the active note. Render using the existing canvas force simulation in a compact 300px sidebar tab.

2. Flowcharts (Mermaid) & Math (KaTeX) Rendering
Support live rendering of architecture diagrams, sequence flows, and formulas inside Markdown notes.
P0 Table Stakes client/src/components/editor/
›

Why It Is P0

Technical architecture notes are incomplete without sequence diagrams and flowcharts. Engineers will not write system specs or RFCs in a tool that cannot render Mermaid diagrams.

Implementation Plan

Add lazy-loaded Mermaid.js and KaTeX extensions to the CodeMirror 6 markdown stack. Only load the heavy parser bundles when a code block contains ```mermaid or math delimiters.

3. AST-Anchored Note-to-Code Links
Enable wikilinks to reference parsed AST symbols (functions, classes, interfaces) that persist across line edits and refactors.
P0 Table Stakes server/src/repos/ast/
›

Why It Is P0

Linking to line numbers is fragile and breaks on the very next commit. Anchoring links to symbol names (e.g. [[repo:backend/auth.ts#TokenService]]) ensures links survive normal code evolution.

Implementation Plan

Leverage the existing tree-sitter AST extraction in repository_symbols table to resolve symbol target offsets dynamically when clicking a code link.

4. Automated Scheduled Backups to Object Storage (#260)
Provide automated, scheduled snapshots of database and vault disk files to S3, GCS, or local backup directory with retention policy.
P0 Table Stakes server/src/backup/
›

Why It Is P0

Teams self-hosting on Docker/VPS refuse to store mission-critical knowledge without automated disaster recovery. A single accidental docker compose down -v currently destroys all data if manual export wasn't run.

Implementation Plan

Implement a lightweight cron worker that runs pg_dump + zips the vault data directory to a configured path or S3 bucket, pruning backups older than N days.

5. Git Webhook Documentation Drift Detection
When a push webhook is received from GitHub/GitLab, inspect changed files and flag linked notes with an "Unverified / Needs Review" trust badge.
P0 Table Stakes server/src/repos/webhooks.ts
›

Why It Is P0

This is the core differentiator of Chapters: closing the gap between code and documentation. It prevents the "truth gap" before it ever starts.

Implementation Plan

When sync_repository finishes, match modified file paths against note_links. For matched notes, set OKF trust status to unverified and notify authors in the in-app notification feed.

6. Image & Asset Attachment Uploads
Allow pasting images from the clipboard directly into notes, saving them to vault assets with instant preview rendering.
P0 Table Stakes client/src/components/vault/NoteEditor.tsx
›

Notes cannot remain text-only. Engineering documentation requires pasting architecture whiteboard photos, UI mockups, and terminal outputs. Stored locally under .attachments/ in the vault disk directory.
